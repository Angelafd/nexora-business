## Descripción

NEXORA BUSINESS es un sitio web comercial para una empresa ficticia
orientada a ofrecer soluciones profesionales para pequeñas y medianas
empresas (PyMEs).

El proyecto fue desarrollado priorizando:

- Diseño responsive
- Arquitectura limpia
- Experiencia de usuario
- Componentización de estilos
- Validación de formularios
- Integración con servicios de terceros
- Buenas prácticas de desarrollo frontend
